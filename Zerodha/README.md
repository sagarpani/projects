# Zerodha Landing Page Clone 🧾

This project is a **prototype clone** of the official [Zerodha](https://zerodha.com) landing page, built using HTML and CSS. It's created for learning and demonstration purposes to showcase frontend development skills.

## 🚀 Features

- Navigation bar with live links to Zerodha pages
- Hero section with image and call-to-action
- Clean, responsive layout using Flexbox
- Pure HTML and CSS without frameworks

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Folder Structure

.
├── index.html
├── Zerodha.css
├── logo.svg
└── landing.png

## 📦 How to Run

1. Clone the repository:
        git clone git clone https://github.com/sagarpani/projects.git
    
    Then navigate into the folder:
        cd projects/Zerodha

2. Open the `index.html` file in your browser.

    > Make sure the image files (`logo.svg` and `landing.png`) are in the same folder as `index.html`.
